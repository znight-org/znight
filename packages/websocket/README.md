# @znight/websocket

> Work in progress ([RFC 0003](../../rfcs/0003-websocket.md)): not published yet.

WebSocket gateways served by the `HttpPlugin` server. This package currently holds the marker
decorators, the gateway options, the exceptions and the envelope of the wire protocol. The runtime
plugin, the transports, the compiler extension and the testing helpers follow the milestones of the
RFC.
